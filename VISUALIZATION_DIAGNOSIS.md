### 1. Root Cause Analysis

#### A. Waveform Root Cause
* **Issue**: The `WaveformVisualizer` component on the Results page was invoked as `<WaveformVisualizer />` without passing any acoustic samples prop. Furthermore, [WaveformVisualizer.jsx](file:///d:/projects/MachineSense2/frontend/src/components/charts/WaveformVisualizer.jsx) contained a 20-line mock stub with 12 hardcoded bars (`[30, 60, 100, ...]` with CSS animation) that completely ignored the 500-point time-domain acoustic waveform array generated by the backend (`result_dict["waveform"]["samples"]`).
* **Fix**: 
  1. Updated [WaveformVisualizer.jsx](file:///d:/projects/MachineSense2/frontend/src/components/charts/WaveformVisualizer.jsx#L1) to accept `samples` (500 normalized floats) and render a time-domain acoustic oscillation curve on a vector SVG canvas.
  2. Updated [Results.jsx](file:///d:/projects/MachineSense2/frontend/src/pages/Results.jsx#L292) to pass `samples={analysisData?.waveform?.samples || []}`.
  3. Connected `<WaveformVisualizer />` to [FrequencyAnalysis.jsx](file:///d:/projects/MachineSense2/frontend/src/pages/FrequencyAnalysis.jsx#L107) under the **`WAVEFORM`** tab mode.

#### B. Spectrogram Root Cause
* **Issue**: 
  1. In [Results.jsx](file:///d:/projects/MachineSense2/frontend/src/pages/Results.jsx#L298), the Log-Mel Spectrogram was hidden inside an optional popup modal rather than rendered directly on the primary analysis dashboard canvas.
  2. In [FrequencyAnalysis.jsx](file:///d:/projects/MachineSense2/frontend/src/pages/FrequencyAnalysis.jsx#L55), clicking the **`SPECTROGRAM`** tab mode did not render the Spectrogram image.
  3. In [analysis.py](file:///d:/projects/MachineSense2/backend/app/routes/analysis.py#L146), spectrogram PNG bytes were stored only in-memory (`store_analysis`). On backend process reloads or when fetching older SQLite database history records, `GET /api/analysis/{analysis_id}/spectrogram` returned HTTP 404 Not Found.
* **Fix**:
  1. Updated [analysis.py](file:///d:/projects/MachineSense2/backend/app/routes/analysis.py#L146) to persist generated PNG spectrogram images to disk under `backend/uploads/spectrograms/{analysis_id}.png`.
  2. Updated `get_spectrogram_image()` endpoint in [analysis.py](file:///d:/projects/MachineSense2/backend/app/routes/analysis.py#L198) to fallback to disk storage if not found in memory, ensuring `GET /api/analysis/{analysis_id}/spectrogram` returns HTTP 200 OK.
  3. Embedded a dedicated **Log-Mel Spectrogram Visualization Card** directly on the [Results.jsx](file:///d:/projects/MachineSense2/frontend/src/pages/Results.jsx#L297) dashboard canvas.
  4. Wired the **`SPECTROGRAM`** tab mode in [FrequencyAnalysis.jsx](file:///d:/projects/MachineSense2/frontend/src/pages/FrequencyAnalysis.jsx#L151) to load the Log-Mel Spectrogram image for the target machine.
